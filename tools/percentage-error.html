Percentage Error Calculator

Compares a measured or experimental value against the accepted/theoretical value — the standard calculation for lab reports.

The formula

% error = (|experimental − theoretical| ÷ |theoretical|) × 100

The absolute value means percentage error is always reported as positive — it measures the size of the discrepancy, not its direction. Commonly used in physics and chemistry lab work to express how far a measured result strayed from the expected value.
