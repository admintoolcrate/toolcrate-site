About this tool

This is a curated set of a few hundred commonly used emoji, searchable by name and keyword and browsable by category — not the full Unicode emoji set of well over a thousand, which would make search noisier for the vast majority of everyday use. Clicking any emoji copies the actual character to your clipboard, ready to paste anywhere that accepts Unicode text.

Nothing you search here is sent to a server — the entire tool runs as JavaScript in your browser tab.
