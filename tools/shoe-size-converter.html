About this tool

This follows a standard, widely-published size chart, using foot length as the underlying reference. Shoe sizing is not perfectly standardized worldwide — different manufacturers and even different shoe models from the same brand can fit half a size differently — so treat this as a reliable starting point rather than an exact guarantee, and check a specific brand's own size chart when it matters.

Nothing you select here is sent to a server — the entire tool runs as JavaScript in your browser tab.
