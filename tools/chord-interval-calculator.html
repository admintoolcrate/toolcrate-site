About this tool

Every chord here is built by stacking a fixed set of semitone offsets on top of the root — a major chord is root, +4 semitones, +7 semitones, for example — using standard 12-tone equal temperament, so the same shape works starting from any root. The interval table below shows all twelve semitone steps from the root and highlights the ones your selected chord actually uses, which is a quick way to see how a chord relates to the full scale around it.

Nothing entered here is sent to a server — the entire calculation runs as JavaScript in your browser tab.
