Countdown Timer

Set a timer and get a sound, title flash, and (if allowed) a browser notification when it's done.

About this tool

The countdown tracks a real end timestamp rather than just decrementing a counter each second, so it stays accurate even if the tab is backgrounded or the browser throttles timers for a while. When it reaches zero it plays a short tone, flashes the browser tab's title, and — if you've granted permission — shows a system notification, so you don't have to keep the tab in view.

Nothing here is sent to a server — the entire timer runs as JavaScript in your browser tab, and stops if you close the tab.
