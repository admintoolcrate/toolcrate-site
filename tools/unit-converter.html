Unit Converter

Convert length, weight, temperature, speed, data, or area units, live as you type.

About this tool

Length, weight, speed, data, and area conversions use fixed, standard multipliers (for example, exactly 25.4 millimeters per inch); temperature uses the correct Celsius/Fahrenheit/Kelvin formulas rather than a simple ratio, since those scales don't share a zero point. The "Data" category here uses decimal multiples (1 KB = 1,000 bytes) — for the binary (1 KiB = 1,024 bytes) distinction that matters for file sizes and storage, see the dedicated File Size Converter.

Nothing you enter here is sent to a server — the entire tool runs as JavaScript in your browser tab.
