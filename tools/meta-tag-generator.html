About this tool

This generates the standard SEO title/description tags, Open Graph tags (used by Facebook, LinkedIn, and most link-unfurling tools), and Twitter Card tags, from one set of fields — Open Graph and Twitter fields fall back to your page title and description automatically when left blank, since that's how most platforms behave when a Twitter-specific tag is missing. Paste the output into your page's <head>, above any other meta tags for best compatibility.

The preview approximates how a shared link commonly renders, but every platform (Facebook, X/Twitter, LinkedIn, Slack, Discord) has its own quirks, image-size preferences, and caching behavior — always test a real link with each platform's official debugger before publishing. Nothing you enter here is sent to a server; the entire tool runs as JavaScript in your browser tab.
