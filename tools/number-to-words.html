About this tool

Numbers are spelled out using the short scale (thousand, million, billion, trillion — each 1,000× the one before), the convention used in US and modern British English. A decimal point is read digit by digit after "point" (so 3.14 becomes "three point one four"), which is the standard, unambiguous way to read a decimal aloud — as opposed to currency-style "and cents" phrasing, which this tool doesn't attempt since it would require knowing the currency.

Nothing you type here is sent to a server — the entire tool runs as JavaScript in your browser tab.
