About this tool

English spelling doesn't map cleanly to syllable count, so this uses the same vowel-group heuristic most readability calculators rely on: count groups of consecutive vowels, then adjust for common patterns like a silent trailing "e" or a word ending in "-le" after a consonant. It's an estimate, not a dictionary lookup — it gets the overwhelming majority of everyday words right, but unusual words and proper nouns can occasionally be off by one.

Nothing you type here is sent to a server — the entire tool runs as JavaScript in your browser tab.
