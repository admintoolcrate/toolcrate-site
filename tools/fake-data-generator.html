About this tool

Every value is randomly assembled from built-in name, street, city, and company word lists — none of it is looked up from a real person or business, and phone numbers use the North American 555 exchange reserved for fiction so they can never collide with a real number. This is meant for populating test databases, demos, and UI mockups where you need plausible-looking data without using anyone's real information.

Nothing generated here is sent to a server — the entire tool runs as JavaScript in your browser tab.
