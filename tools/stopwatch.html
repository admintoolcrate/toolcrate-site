About this tool

Elapsed time is measured from a real start timestamp rather than accumulated tick-by-tick, so pausing and resuming stays accurate over long sessions. Each lap records both the split (time since the previous lap) and the cumulative total, with the fastest and slowest splits highlighted once you have three or more laps.

Nothing here is sent to a server — the entire stopwatch runs as JavaScript in your browser tab.
