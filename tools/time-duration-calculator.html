About this tool

If the end time is earlier than the start time, check "End time is the next day" to have it treated as crossing midnight (e.g. 22:00 to 06:00 becomes an 8-hour overnight span) — without it, an end time earlier than the start is flagged as invalid rather than silently guessed at.

Nothing entered here is sent to a server — the entire calculation runs as JavaScript in your browser tab.
