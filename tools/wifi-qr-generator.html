About this tool

The QR code encodes a standard WIFI:T:...;S:...;P:...;; payload that every major phone's camera app recognizes, with special characters in the network name and password (backslashes, semicolons, commas, colons) automatically escaped per the spec so networks with punctuation in their names still scan correctly. It's generated with the same from-scratch ISO/IEC 18004 QR encoder as our QR Code Generator — real Reed-Solomon error correction, not a hosted image API.

Your network name and password are only used locally to build the QR code — nothing is sent to a server, and the password never leaves your browser tab.
