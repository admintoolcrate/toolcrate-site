About this game

Made for babies and toddlers (with a grown-up nearby): a target color is named out loud (and shown as a circle), and the child taps the matching color among the options below. A correct match pops and celebrates; a miss just gently shakes so they can try again — nothing is ever wrong for long. Uses your browser's built-in speech synthesis, with the color name shown on screen either way.
